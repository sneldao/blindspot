# Desktop Operator — The Controller

Operate a remote GUI with vision and clicks.

## What it does

Uses a cloud desktop to interact with applications that require a screen. Takes screenshots, clicks, types, and observes like a human operator.

## Primitives

- Desktop

## Why it matters

Not every workflow has an API. Some tools only expose themselves through a GUI. A desktop agent bridges that gap without needing a local screen. The essay thesis: *the last mile of automation is a screen.*

**The experience (planned): watch the operator work.** A live view of the cloud desktop as the agent drives a real legacy GUI application — clicking, typing, observing — with its reasoning narrated alongside the stream. The visitor sees a machine use software built for humans.
