# Browser Profiles — The Chameleon

Wear an identity, shed it, prove that nothing followed you.

## What it does

Uses Solari's browser profiles to run tasks under a persistent identity, then contrasts this with an ephemeral browser that leaves no fingerprint behind. Demonstrates exactly what follows you — IP reputation, canvas fingerprint, cookies, storage — and what vanishes.

**The experience (planned): a fingerprint audit, live.** The visitor loads a page that audits their own local browser (fingerprint, IP class, storage). Then, one click: the same audit runs inside a Solari cloud browser — first a persistent profile, then an ephemeral session — with results rendered side by side. The visitor watches their own identity accumulate, then watches it not exist.

## Why it matters

The interactive proof of the ephemerality thesis: *an agent that persists is an agent that can be profiled.* This is the canonical demonstration of Scudra's ownable idea.
